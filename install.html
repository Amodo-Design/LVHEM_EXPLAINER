What this illustration assumes

One GB200 NVL72 rack is one inference unit: 72 GPUs with internal NVLink retained. The approved model must fit within that unit.

The approximately 1 Gb/s link is the proposal’s example, not a validated capacity for every workload. Existing management links are removed in this illustration; permitted telemetry uses the monitored frontend.

No storage relocation is shown. Added spacing is for legibility. Model setup, verifier integrity and covert-channel controls still need agreed procedures.

Passing one sampled check is not proof that a whole data centre is inference-only. The displayed outcomes are a visual analogy, not DiFR execution.
